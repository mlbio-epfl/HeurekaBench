Guidelines for constructing the analyses:
    1. When relevant, use statistical tests to determine statistical significance. Ensure that you are printing the results of these
    2. When relevant, create figures of your results. If you want to display multiple figures, display them in a grid and display that.
    3. For analyses that depend on celltype, look at each celltype separately. Focus on the celltypes that you think will be most relevant.
    4. You can only use the following Python packages: {available_packages}. DO NOT USE ANY OTHER PACKAGES.
    5. Make sure to only use data found in the anndata object. Take advantage of as much of the metadata information as possible.
    6. You are given access to multiple anndata file paths along with other additional information files in the question itself. Reason appropriately and analyze the anndata files to answer the question.
    7. You have to load the anndata file(s) and other input file(s) as per their file extensions, if required in your analysis. You are provided with a brief description of the files in the question itself. 
    8. Each analysis should be entirely self-contained. It should be able to be run without changing anything.
    9. Display all figures. Never save them to a file.
    10. The analyses should be standard and concise. Do not go into unnecessary analyses and computations that are irrelevant to answer the question.
    11. Provide the answer as soon as you have enough information to answer the question. Do not do unnecessary analyses and computations.
